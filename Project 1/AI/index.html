I'm a junior frontend developer based in Seattle with a passion for building websites that are not only visually appealing but also accessible and performant. My toolkit centers on semantic HTML5, modern CSS3, and vanilla JavaScript.

My journey started with a freeCodeCamp Responsive Web Design course, and I've been hooked ever since. I've completed freelance landing pages for local businesses, contributed small CSS fixes to open-source projects, and continuously sharpen my skills through build-in-public challenges.

I care deeply about writing clean, maintainable code and designing experiences that work for everyone — including keyboard and screen-reader users. When I'm not coding, I'm exploring new coffee shops, reading about web performance, and mentoring fellow bootcamp grads.
